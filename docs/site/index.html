Colony Kernel is deterministic mission control for AI-agent colonies. Every state change, budget, and human approval goes through an auditable, fail-closed core. An agent saying "this passed" is not a verification result, and nothing in the kernel treats it as one.

The problem it solves. Hand work to an AI agent and "I finished and it works" is a claim you cannot verify. A model that is wrong about its own success is worse than no agent at all. Colony makes the agent propose and a deterministic core decide. Trust comes from replayable evidence, not from the model's word.

What's inside

22-stage state machine

Default-deny edge table. Unlisted transitions are illegal, not "unlikely". Legality precedes storage.

Apply-once event reducer

Accepted events carry canonical hash + CAS version + monotonic sequence. Replay reconstructs identical state.

Content-addressed approvals

SHA-256 over RFC 8785 JCS bytes, bound to the exact transition, consumed ≤1, expired at commit.

Budget ledger

Immutable limits with CAS rows. Agents can't mint resources or vote themselves a raise.

Deny-by-default roles

No self-mutation, no self-publication. Reserved public states are structurally unreachable.

Durable rejections

Refused commands leave evidence and never mutate state. Audit trails don't have gaps.

The inversion

Multi-agent frameworks let the LLM drive workflow state, so workflow is only as reliable as the model. Colony flips the trust boundary: models suggest, a deterministic kernel decides. Verification is proven by replayable evidence, not claimed by the model that wrote the code.
